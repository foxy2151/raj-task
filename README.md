## task 1 
This project is developed as part of the CODTECH Internship Task-1.
The main objective of this project is to fetch real-time weather data from a public API and visualize it using graphs.

In this project, the OpenWeatherMap API is used to collect weather forecast data such as temperature and humidity for a selected city. The fetched data is then processed and displayed in the form of graphs using Matplotlib.

This helps in understanding weather patterns in a visual and easy-to-analyze format.

## task 3: AI Chatbot with NLP

This project is developed as part of the CODTECH Internship Task-3, which involves building an AI chatbot using Natural Language Processing (NLP) techniques in Python. The chatbot utilizes the NLTK library to process user input through tokenization and lemmatization, enabling it to understand and respond intelligently to user queries. The chatbot operates interactively in the terminal, allowing real-time conversation and demonstrating the practical application of NLP concepts in building intelligent systems.
