## task 1 
This project is developed as part of the CODTECH Internship Task-1.
The main objective of this project is to fetch real-time weather data from a public API and visualize it using graphs.

In this project, the OpenWeatherMap API is used to collect weather forecast data such as temperature and humidity for a selected city. The fetched data is then processed and displayed in the form of graphs using Matplotlib.

This helps in understanding weather patterns in a visual and easy-to-analyze format.
